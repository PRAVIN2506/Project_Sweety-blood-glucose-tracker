
# Sweety – Blood Glucose Tracker

A full-stack web application that allows diabetes patients to record, manage, and monitor their daily blood glucose readings.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- Prisma ORM

### Database
- PostgreSQL

### Authentication
- JWT
- bcrypt

## Features

- User registration and login
- Secure password hashing
- Add, view, update, and delete glucose readings
- Maximum four readings per day
- Daily glucose reports
- Month-to-date reports
- Previous monthly reports

## Project Structure

- `client/` – React frontend
- `server/` – Express backend
- `docs/` – Project documentation
